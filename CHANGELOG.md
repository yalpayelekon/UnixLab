# Changelog

All notable changes to UnixLab will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and
the project will use semantic versioning for independently released tools and
libraries once their public APIs stabilize.

## [Unreleased]

### Added

- Initial Cargo workspace and project governance foundation.
- Needle 0.1 single-file UTF-8 regular-expression search with terminal-aware
  match highlighting and grep-compatible core exit statuses.
- Tide 0.1 streaming HTTP/HTTPS GET client with bounded redirects and timeout.
- Reed 0.1 sed-inspired stream editor with addresses and `s` / `p` / `d`.
- Quartz 0.1 jq-inspired JSON path query with compact or pretty output.
- Resolver 0.1 dig/host-inspired DNS address lookup via the system resolver.
